#  Skillora — AI Career Growth Platform

Skillora is an AI-powered platform built to help students and aspiring professionals make better career decisions, learn the right skills, and prepare themselves for future opportunities.

Choosing what to learn, which projects to build, or how to prepare for internships can often feel confusing. Skillora aims to simplify this journey by providing personalized guidance, project recommendations, skill suggestions, and AI-powered interview preparation.

This project is currently under development, and I’m continuously working on improving its features and user experience.

---

##  What Skillora Helps With

###  Personalized Learning Path
Skillora helps users understand what skills they should focus on based on their career interests and goals.

###  Project Recommendations
Finding good projects to build can be challenging. Skillora suggests practical project ideas that help users improve their skills and strengthen their portfolios.

###  Career Preparation
From understanding required skills to preparing for internships and jobs, Skillora provides guidance to help users move forward confidently.

### AI Interview Practice
Users can practice interview questions with AI assistance, improve their answers, and build confidence before real interviews.

## ⚙️ Getting Started

To run Skillora locally:

### Clone the repository

```bash
git clone https://github.com/SurbhiSoni1/Skillora.git
```

### Install dependencies

```bash
npm install
```

*Start the project*

```bash
npm run dev
```

Make sure to add your required environment variables in a `.env` file before running the application.
